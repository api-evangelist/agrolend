# Agrolend

> Agrolend Sociedade de Credito, Financiamento e Investimento S/A (CNPJ 43.774.196/0001-84) is a
> Banco Central do Brasil regulated agricultural-credit fintech in Sao Paulo, founded in 2020. It
> originates working capital, receivables discount, liability extension and inter-chain credit for
> small and mid-sized Brazilian rural producers, distributed through agricultural retailers,
> cooperatives and input industries, and funded in part through FGC-covered LCA notes sold on
> third-party investment platforms.

## Status of the API surface

Agrolend publishes **no developer portal, no API reference, no SDK and no machine-readable
contract**. Probed 2026-09-13:

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, Protobuf or WSDL at any location on any Agrolend host.
- No /llms.txt, no /apis.json, no /.well-known/ document of any kind (all 404).
- No A2A agent card and no MCP server.
- No first-party package on npm, PyPI, RubyGems or crates.io. The GitHub organisation exists but is
  empty.
- Not a participant in Open Finance Brasil, so no FAPI-BR regulated API either.

The only API host reachable from the public internet is `parceiro.agrolend.agr.br`, a Spring Boot
partner-area backend that answers HTTP 401 with `WWW-Authenticate: Basic` on every path. Two further
hosts, `docs.agrolend.agr.br` and `portal.agrolend.agr.br`, resolve to a load balancer that returns
504 behind a wildcard certificate that expired 2025-03-06.

An agent cannot integrate with Agrolend today. Partnership is the only documented route in, via the
registration form.
